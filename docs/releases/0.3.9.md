### 🌤 天气与定位

- CoreLocation 成功时，按**当前网络**（默认网关 MAC）记住精确坐标；同一 Wi-Fi/有线网络下定位失败时优先复用，避免同城跨区（如家/公司）被 IP 猜错区
- IP 定位兜底：**BigDataCloud 优先**，失败时使用 **api.ip.sb**（替换 ip9.com.cn，市级坐标更稳定）
