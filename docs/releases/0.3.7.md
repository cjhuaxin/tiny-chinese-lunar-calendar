## ✨ 小小万年历 0.3.7

修复使用代理 / VPN 时「检查更新」报「获取升级信息时出现错误」。

---

### 🔄 检查更新更稳

- 修复开启代理 / VPN 时点击「检查更新」出现「获取升级信息时出现错误」的问题

  原因是更新源走 Cloudflare，而 Cloudflare 会对机房 IP 间歇性下发人机验证，返回一个验证网页而不是更新信息，更新程序无法识别。

- 更新源改为双通道：主更新源取不到有效更新信息时，自动切换到 GitHub 备用源
- 每次检查都会重新判断走哪条通道，中途开关代理也能正确切换

---

### 📦 安装与升级

- **0.3.x 用户**：点击菜单栏图标 → 检查更新，即可自动升级

  如果此前一直报错升不上来，请临时关闭代理后再检查更新，或直接下载下方 **xiaoxiao-wannianli-0.3.7.dmg** 手动安装；装上本版后即可恢复正常。

- **0.2.5 及更早版本**：请手动下载下方 DMG 安装，之后即可恢复自动更新
