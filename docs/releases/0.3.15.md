## ✨ 小小万年历 0.3.15

天气位置更准、更省心：拿不到精确定位时，不再只能依赖不准的 IP 定位。

---

### 📍 天气位置

- **默认城市**：设置 → 显示天气 → 天气位置，可设置无法精确定位时使用的城市；首次精确定位成功后会自动填好
- **按网络记住位置**：点天气卡片上的城市名即可搜索并选择位置（可精确到区县，如「南山」），之后连上同一个网络会自动沿用
- **精确定位优先**：系统定位可用时始终以它为准；其次是当前网络记住的位置，然后是默认城市，最后才是 IP 定位
- 无法精确定位时，顶部会出现一条可关闭的提示，一键设置位置；关闭后同一网络不再提示
- 开着 VPN（Clash、Tailscale 等）也能正确识别所在网络
- 精确定位失败后，10 分钟内重新打开日历会直接显示备用位置的天气，不再每次都等待定位超时
